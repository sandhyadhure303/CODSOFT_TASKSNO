Tic-Tac-Toe Game 🎮

📌 Project Description

This is a simple Tic-Tac-Toe game developed using C++.
It is a two-player console-based game where players take turns placing X and O on a 3×3 board. The first player to get three matching symbols in a row, column, or diagonal wins the game.

🛠️ Technologies Used

- C++
- C++ Standard Library
- Console/Terminal

🎮 Features

- Two-player gameplay
- 3×3 game board
- Checks for winning combinations
- Detects draw/tie situations
- Simple and easy-to-use interface

▶️ How to Run

1. Download or clone the repository.
2. Open the C++ source file in a C++ compiler.
3. Compile the program.
4. Run the program and follow the instructions displayed on the screen.

🕹️ How to Play

1. Player 1 uses X.
2. Player 2 uses O.
3. Players take turns selecting an available position on the board.
4. The player who gets three symbols in a row, column, or diagonal wins.
5. If all positions are filled without a winner, the game ends in a draw.
